# Tripgroup Design System

Tripgroup uses an editorial dark aesthetic with high-contrast typography, translucent glassmorphism containers, and vibrant terracotta brand accents.

## Design Principles

1. **Editorial Elegance**: Editorial serif headlines paired with micro-monospaced captions.
2. **Tactile Simplicity**: Translucent glass surfaces (`glass-card`) with subtle border grid lines.
3. **Intentional Feedback**: Floating status toasts, active animations, and ambient glow effects.

## Color Palette

- **Brand Primary**: `#FF6321`
- **Background**: `#050505`
- **Surface Card**: `rgba(255, 255, 255, 0.05)`
- **Border**: `rgba(255, 255, 255, 0.1)`
- **Text Main**: `#FFFFFF`
- **Text Muted**: `rgba(255, 255, 255, 0.5)`

## Components

- **Header / Hero**: Editorial title text with background atmospheric gradients.
- **Card**: Translucent container with hover border highlights and shadow elevation.
- **Modal**: Dark blurred backdrop with centered dialog container.
- **Toast**: Fixed bottom pill with animated slide entrance.
